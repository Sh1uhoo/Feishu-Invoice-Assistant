# 发票整理助手（桌面版）

把「发票整理 + 飞书购买申请/发票状态查看 + 对比」做成一个 Windows 桌面软件。

## 功能

| 页签 | 功能 |
|---|---|
| **整理** | 扫描发票根目录的订单文件夹（`0X-名称-金额元`），展示订单 / 金额 / 文件构成 / 三合一状态，一键汇总购买记录截图 |
| **飞书** | 对接飞书开放平台 API，拉取你发起的「购买申请」和「发票提交」，展示金额 / 概述 / 状态 / 时间 |
| **对比** | 把本地订单和飞书单据按金额匹配，列出：未申请购买 / 已申请未提交发票 / 已闭环 |

> 三合一 PDF 的合并由你已有的合并脚本负责，软件不参与合并（避免合并方式不一致）。

## 运行方式

### 方式一：直接运行 exe（推荐）
运行 `dist\发票整理助手.exe`。

### 方式二：源码运行
```bash
pip install -r requirements.txt
python main.py
```

## 首次使用：配置飞书（查看购买申请/发票 必做）

软件的「飞书」功能使用**用户身份权限**（扫码授权登录），需要三步：**建应用 → 开权限 → 扫码授权**。

### 第 1 步：创建企业自建应用
1. 打开飞书开放平台：<https://open.feishu.cn/>，用你的飞书账号登录
2. 进入**开发者后台** → 点**创建企业自建应用**，名称随意（如"发票助手"），创建完成
3. 进入该应用 → 左侧**凭证与基础信息**，复制 **App ID** 和 **App Secret**（填到软件里）

### 第 2 步：开通权限（用户身份权限）
1. 左侧**权限管理** → 开通权限 → 切到**用户身份权限 user_access_token** 标签，添加：
   - `approval:instance:read`（获取审批实例详情）
   - `approval:instance:write`（操作审批实例：提交/撤回）
2. 左侧**版本管理与发布** → 创建版本 → 提交发布（用户身份权限通常免审或由开发者本人直接生效）
3. 左侧**安全设置** → **重定向 URL** → 添加：`http://localhost:8822/callback`

### 第 3 步：在软件里扫码授权
1. 打开软件「飞书」页 → 填 **App ID / App Secret** → 保存配置
2. 点**扫码授权登录** → 浏览器弹出飞书授权页 → 用你的飞书账号扫码/确认
3. 授权成功后软件自动获得凭证，点**测试连接**确认 → **拉取数据**

> 授权凭证只保存在本机 `config.json`，不会上传。token 有效期约 2 小时，过期后重新扫码即可。

## 整理功能说明

- **订单文件夹识别**：根目录下形如 `01-名称-111元` 的文件夹会被识别为订单（序号 + 金额）
- **三合一状态**：显示该订单是否已有对应金额的三合一 PDF（文件在 `三合一\` 目录）
- **购买/支付截图自动区分**：按文件名关键词（支付/付款/账单 vs 购买/订单）区分；无法区分的按修改时间排序（靠前=购买记录，靠后=支付记录）
- **汇总购买记录**：把每个订单里的购买/支付截图复制到 `购买记录\` 目录，同名不覆盖

## 配置文件

- `config.json`：飞书凭证 + 发票根目录 + 队名（自动生成）
- 软件默认发票根目录：`D:\施宇豪\桌面\发票`（可在「整理」页修改）
